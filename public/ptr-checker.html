Reverse DNS (PTR) checker

Find out whether your sending IP has a PTR record and whether it forward-confirms. Enter an IP address or a domain. Free, no signup.

What a good result looks like

  • PTR present for the sending IP.
  • Forward-confirmed: the hostname resolves back to the same IP.
  • Hostname matches the server that actually sends mail.
  • No stale or mismatched reverse records.
