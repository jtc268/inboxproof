Where it goes
Add a TXT record at the domain root (host name blank or @) with the value above. Only one SPF record is allowed per domain.

Provider quick-steps

Cloudflare — DNS → Records → Add record. Type TXT, Name @, Content the record, TTL Auto.

GoDaddy — DNS → Manage Records → Add New Record. Type TXT, Name @, Value the record.

Namecheap — Manage DNS → Add New Record. Type TXT, Host @, Value the record.

AWS Route 53 — Hosted zone → Create record. Type TXT, Record name @, Value the record.

Google Workspace — DNS → Custom resource records. Type TXT, Name @, Content the record.
