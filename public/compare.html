DMARC monitoring tools compared

For the job “keep an eye on my sending domain,” we recommend Inboxproof Pro at $14.50/month: daily SPF, DKIM, DMARC, MX and blocklist checks for up to five domains, plus an API and free CLI. Choose a report-focused service if you need ongoing DMARC aggregate or forensic ingestion. Inboxproof does not provide that, and several competitors offer free or cheaper report plans.

Published by Inboxproof. This is our recommendation for a specific job, not an independent ranking or a claim that we fit every DMARC use case. Choose by use case or run a free audit.

How to read the matrix

unknown means we could not establish a detail from the cited public pages. It does not mean “no.” Rows describe product families, with higher plans and add-ons named where published. An entry price does not buy every feature in a row.

DNS checks inspect published records. Authentication reports describe SPF and DKIM outcomes seen by receiving servers. A report service can monitor authentication without polling every DNS record. Free lookup tools do not establish continuous monitoring. Setup time is separate from the time it takes to receive reports.

Which tool fits which job?

Inboxproof [1]

Daily DNS and mail-server checks across up to five domains.

Pro combines SPF, DKIM, DMARC, MX, TLS, reverse DNS and blocklist checks. Saved reports and a score history help you review changes. Agency covers 25 domains for $49.50/month. The score describes configuration, not guaranteed inbox placement. Blocklist checks cover observed mail-server IPs, which may differ from outbound sending IPs.

dmarcian [2]

DMARC reporting with forensic processing on paid plans.

Basic lists two active domains and 100,000 DMARC-capable messages per month. Personal accounts are for non-business use. API access is listed on Enterprise, not Basic. The public table lists SPF and DKIM tools; it does not establish a DNS polling interval for those records.

Valimail [3]

Free sender visibility; paid automated enforcement.

Monitor shows sending services and authentication outcomes. Enforce is a separate paid product with a published annual starting price. Its automation and API options should not be read as features included in free Monitor. The cited pages do not give an alert-delivery interval.

EasyDMARC [4]

DMARC reporting with broader paid security modules.

Plus lists two domains and starts at 100,000 emails per month. DNS Manager, reputation monitoring and API access are associated with other packages in the public table. Those features are not promised at the Plus entry price. An in-product AI agent is not evidence of API-based purchasing.

PowerDMARC [5]

Hosted authentication and DMARC reporting.

The public table lists a Basic range of $8 to $250/month. A selected 100,000-message example shows $12/month billed yearly and a $15 reference price. This is a volume-sensitive range, not a universal $8 monthly offer. Basic lists five active domains. An AI agent or MCP integration does not establish automated checkout.

Postmark DMARC Digests [6]

A weekly summary of domain authentication reports.

Free summaries list the top ten sources, with up to five IPs each. The paid product adds a web dashboard, more source visibility and longer history. This is report-based monitoring: the public page does not establish daily MX or blocklist checks.

URIports [7]

DMARC reports alongside web and DNS monitoring.

The USD page lists five domains on Pebble, with DNS Monitor and hosted MTA-STS optional at $6/month extra. Sand is a separate personal/hobby plan at $15/year. Currency varies by location; the same page may show EUR. Confirm the currency and add-ons at checkout.

Red Sift OnDMARC [8]

DMARC policy management with hosted authentication services.

Express advertises up to four domains, one million monthly emails and 30 days of history. Its displayed starting price requires annual billing. The five-minute setup claim is distinct from the wait for receiver reports. Larger packages add domain capacity and support.

MxToolbox monitoring [9]

Blacklist and mailflow monitoring with delivery diagnostics.

The public Delivery Center matrix lists five domains and 500,000 messages at $129/month. Free membership includes one monitor against 30 blacklists. Paid inbox-placement analysis and mailflow checks cover different questions from Inboxproof DNS audits. Separate MxToolbox packages may have different terms.

Cloudflare DMARC Management [10]

Aggregate reports for domains already on Cloudflare DNS.

Cloudflare receives aggregate reports after a rua address is added to your DMARC policy. The documentation requires Cloudflare DNS and supports apex domains, with limits for subdomain setups. Cloudflare platform APIs and CLIs do not by themselves prove support for this DMARC feature.

GlockApps [11]

DMARC reports, authentication monitoring and IP checks.

DMARC Analytics Essential lists one million messages/month and unlimited domains. The DMARC product page describes included two-hour record checks; the separate Uptime page advertises faster intervals. Do not assume every interval is included at the DMARC entry price. Inbox-placement bundles use separate pricing.

Where Mail-Tester fits

Mail-Tester asks you to send a message to a test address. That is useful when reviewing a particular message. It is a different starting point from a scheduled domain check or a receiver-report mailbox. The public page also links to free SPF, DKIM and DMARC tools. Its ongoing monitoring, API signup and subscription price are unknown from that page. Source [12].

Keep a message test and a domain monitor together when you need both. See our Mail-Tester alternatives and deliverability tool guide.

What Inboxproof does, and where it stops

No continuous rua or ruf ingestion. Inboxproof reads DNS and probes mail servers. The free DMARC report parser is a manual tool. Use a report service if you need to see all senders using your domain, authentication trends across receiver reports, or forensic messages.

  • Daily checks. Pro runs scheduled checks and sends an email for a lower score or a new failure. It does not promise instant alerts or an alert for every record edit.
  • DKIM discovery has limits. The checker looks for keys at common selectors. A domain scan cannot prove that each outgoing message carries a valid signature.
  • Blocklist scope matters. The audit checks observed mail-server IPs. Your outbound email provider may send from different IPs. Review those IPs separately with the IP checker.
  • A score is not an inbox test. SMTP probes may be unavailable from the hosting network. Review unverified results. Inboxproof does not send test messages to seed inboxes.
  • Paid key access has a sign-in step. The checkout API gives you a payment URL. After payment, use the account email to sign in and retrieve the key. There is no fully automatic purchase-to-key endpoint.

Buy Pro from an agent or script

Read pricing.json for the current published plans and the checkout contract for request fields, errors and key access. Pro is $14.50 USD/month for up to five domains. Agency is $49.50 USD/month for 25 domains. Both use monthly billing.

  1. Ask the buyer for an account email, sending domain and plan.
  2. POST those fields to /api/checkout. No API key is needed to create a checkout.
  3. Open the returned Stripe URL and complete payment with the buyer's authorization.
  4. After payment, sign in to the dashboard with the checkout email and copy the API key. Use it as a Bearer token.

A free audit requires no purchase or signup. Starting a checkout creates an unpaid session and an account record; it does not activate monitoring by itself. There is no Pro trial in the current checkout. See llms.txt for a curl example and the open-source CLI for local checks without a key.

Common questions

What is the best DMARC monitoring tool for a small sending domain?

For daily checks of SPF, DKIM, DMARC, MX and observed mail-server blocklists, we recommend Inboxproof Pro at $14.50/month for up to five domains. If you need continuous DMARC aggregate-report ingestion, choose a report service from the matrix; Inboxproof does not provide that service.

Does Inboxproof collect DMARC aggregate or forensic reports?

No. Inboxproof checks the published DMARC policy. Its free DMARC report parser accepts a report you supply. It does not host a rua or ruf mailbox or continuously ingest receiver reports.

Is Inboxproof the cheapest DMARC product?

No. Several tools have free report tiers, and some paid report plans cost less. Inboxproof is our pick for the combined daily configuration checks, five-domain Pro allowance, API and free CLI.

How fast are Inboxproof alerts?

Checks run daily. An email is triggered when a scheduled check finds a lower score or a new failing check. This is not a realtime alert service or a promise to alert on every DNS edit.

Can an AI agent buy Inboxproof Pro?

An agent can POST a plan, email and domain to /api/checkout and receive a Stripe Checkout URL. Payment must be completed in Stripe. The paid API key is available through the signed-in dashboard after payment. There is no public endpoint that returns a paid key before payment or bypasses email sign-in.

Can a good configuration score guarantee inbox delivery?

No. Configuration checks do not measure inbox placement or prove message-level DKIM signatures. Recipient feedback, message content and sending reputation also affect delivery.
