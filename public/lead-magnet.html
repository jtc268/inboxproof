What's in the checklist

12 checks, 3 categories

DNS Records
  • 1. MX record points to a live mail server
  • 2. SPF record includes all sending services
  • 3. DKIM signature is valid and not expired
  • 4. DMARC policy is set and aligned
  • 5. PTR (reverse DNS) matches the sending IP
IP Reputation
  • 6. Sending IP is not on any major blocklist
  • 7. TLS/STARTTLS is enabled on the mail server
  • 8. IP has a clean history (no prior spam abuse)
Sending Practice
  • 9. Unsubscribe link is present and works
  • 10. List is cleaned (no stale or bounced addresses)
  • 11. Send volume is warmed up gradually
  • 12. Content passes spam filter checks
